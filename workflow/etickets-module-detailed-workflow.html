A New E-Tickets — How to create

  1. Go to E-Tickets → New E-Tickets (`etickets.php`).
  2. Enter PNR, booking date, mobile, and email.
  3. Open Search Flight, choose One-way or Round-trip, select airports/dates, then search.
  4. Pick the flight(s). Sector, airline, and flight details appear on the ticket preview.
  5. Set passenger count and fill each passenger (name, type, ticket no., seat, meal, services).
  6. Enter Base fare, Tax, and Total (you can hide fare if needed).
  7. Review the live A4 ticket preview.
  8. Click Save Ticket and/or Download Ticket to generate PDF and store the record.
Saving calls `ajax/save_ticket.php`, stores PDF under `uploads/tickets/`, and inserts/updates `saved_tickets` (including `passengers_json`).

B All E-Tickets — How to manage

  1. Go to E-Tickets → All E-Tickets (`eticketslist.php`).
  2. Use From / To date filters by Created, Departure, or Arrival date.
  3. Use the search box to find PNR, passenger names, airline, or sector.
  4. View — open the saved PDF.
  5. Edit — opens the New E-Tickets form with `edit_id` to change full ticket details.
  6. Quick Update — update key fields (PNR, fare, sector, airline, etc.) from the list modal.
  7. Delete — removes the database row and the PDF file.
Use date filters before large searches. Delete carefully — PDF and record are both removed.

C E-Tickets Master — How to configure

  1. Go to E-Tickets → E-Tickets Master (`e-ticket-master.php`).
  2. Open Important Info to edit notes shown on tickets (ID rules, airport reporting time, etc.).
  3. Open Banner Image to upload/activate the header banner used on tickets.
  4. Save changes — new tickets pick up the active banner and important information automatically.
Master settings feed into New E-Tickets preview and generated PDFs. Configure these once before bulk ticket issuing.

! Recommended daily workflow

  1. Setup once: Master → Important Info + Banner.
  2. Issue tickets: New E-Tickets → fill → preview → Save/Download.
  3. Follow up: All E-Tickets → filter by travel date → View / Edit / Resend PDF.
  4. Cleanup: Delete cancelled/wrong tickets so the list stays clean.
This module sits after Admin Login in the software workflow: Login → E-Tickets Master → New E-Tickets → All E-Tickets.
