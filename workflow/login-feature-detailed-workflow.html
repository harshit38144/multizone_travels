A Admin Login — How to use

  1. Open the Admin Login page (`admin/index.php`).
  2. Type your Username in the name field.
  3. Type your Password.
  4. Click Login.
  5. If correct, the system creates a session (`id`, `name`, `email`, `role`) and opens the dashboard.
  6. If wrong, you see “Invalid Username or Password!” and stay on the login page.
Tip: Keep credentials private. Every login attempt (success or fail) is recorded in admin log history.

? Forgot Password — How to use

  1. On the Admin Login page, choose Forgot Password.
  2. Enter the email registered for your admin account.
  3. Submit the request.
  4. Check your inbox for the reset email (link valid for 1 hour).
  5. Open the link, set a new password, then login again.
For security, the same confirmation message is shown whether or not the email exists in the system.

B Privilege Member Login — How to use

  1. Open Privilege Member Login (`privilege_login.php`).
  2. Enter the email registered on your privilege card.
  3. Click Send verification code.
  4. Open your email and copy the 6-digit OTP (valid 10 minutes).
  5. Enter the code and click Verify and continue.
  6. On success, you are redirected to your Privilege Profile.
No password is needed for privilege login — email + one-time code only. You can go back and use a different email if needed.

! What the system does behind the scenes

  1. Validate input — username/password or email/OTP format.
  2. Check database — match admin credentials or privilege traveller email.
  3. Create secure session — store user identity and role.
  4. Apply access control — Admin role opens CRM/dashboard modules; Privilege role opens member portal only.
  5. Log activity — successful logins and failed attempts are recorded for audit.
  6. Handle errors safely — show clear messages without exposing internal details.
This login feature is the first gate of the full software workflow: Entry → Authentication → Dashboard / Portal.
