1 Leads

Page: crm/leads.php · Intake: crm/lead_intake_pending.php · Form: lead create/edit modal

Open CRM → Leads→ Create / Intake / Search→ Assign + Stage→ Generate Quotation→ Confirmed / Lost

How to create a lead (manual)

  1. Click Create Lead.
  2. Enter guest name, phone, email.
  3. Select Lead Source (from Lead Source master).
  4. Choose Assign To (self or CRM user).
  5. Select services (Tour Package, Flight, Hotel, Cruise, Vehicle, etc.).
  6. Pick destination(s), travel dates, nights, adults/children.
  7. Add tour preferences / notes / attachments if needed.
  8. Save — system creates Lead UID (e.g. LD-0007).

How to capture lead via customer form link

  1. Click Send Link (preference form).
  2. Choose fields to include and copy/send the link.
  3. Customer submits the public form.
  4. Submission appears under Pending.
  5. Open Pending → review data.
  6. Approve to convert into a CRM lead, or Reject / Delete.

Leads list features

  • Search by name, phone, destination, quotation UID, etc.
  • Filter by Financial Year.
  • Columns: Lead ID, Guest, Destination, Travel Date, Services, Source, Assigned, Stage, Actions.
  • Column visibility settings (per admin).
  • Pagination (10 / 25 / 50 per page).
  • View / Edit / Call / More menu (duplicate, delete, quotation).
  • Trash — soft-deleted leads; restore available.

Stage rules (important)

  • New Lead — created, no quotation yet.
  • Quoted — quotation exists for the lead (auto).
  • Confirmed — quotation marked tour confirmed / booked (auto).
  • Lost — manual mark when opportunity is closed lost.
  • Auto stages update from quotation activity; you can still mark Lost.
Instruction tip: Always assign an owner and set destination/travel date so the lead list and quotation prefill stay accurate.

3 Quotations

List: quotation-generator-list.php · Editor: quotation_generator.php · Templates · Terms

Lead / New Quote→ Guest & Tour→ Flight/Train→ Hotels→ Itinerary→ Terms→ Pricing→ Save / PDF / Mail / Book

A) Quotation list — instructions

  1. Open CRM → Quotations → Quotations.
  2. Search/filter existing quotes.
  3. Click a row to edit in the generator.
  4. Use Book / Confirmed to open Confirm Tour modal.
  5. Use menu to Delete (permanent).
  6. Create new from list or from a Lead action.

B) Templates & Terms

  1. Templates — reusable quotation layouts/content starters.
  2. Terms & Policies — maintain policy text used in wizard step 5.
  3. Keep terms updated seasonally (cancellation, payment, baggage).

C) Generator wizard — step by step

  1. Guest & Tour — guest name, phone, email, destination, dates, pax, nights, link/select lead.
  2. Flight / Train — add sectors, search flights (same style as e-tickets), arrival/departure, suppliers.
  3. Hotel Details — city-wise hotels, check-in/out, rooms, meal plan; search hotel master.
  4. Itinerary — day-wise plan, titles/descriptions, images (search/import), AI suggest (if configured), sightseeing/suppliers.
  5. Terms & Policies — pick/edit policy content from master.
  6. Pricing — cost sheet (flight, hotel, vehicle, addons), margins, selling price options / packages.

D) After building the quote

  • Save — stores quotation JSON + meta in crm_quotations.
  • Preview / PDF — client-ready document.
  • Supplier mail — email hotels/flight suppliers with attachments.
  • Confirm Tour — marks booking confirmed; lead stage becomes Confirmed.
  • Editing an existing quote repairs/normalizes legacy formats when needed.
Instruction: Prefill from Lead whenever possible so guest, destination, and dates stay consistent. Complete Flight → Hotel → Itinerary before Pricing for accurate costing.

4 Bookings

Sidebar: All Bookings · Add New Booking · Confirm flow lives on Quotations list today

Menu structure

  • All Bookings — crm/bookings.php (list of confirmed tours/bookings).
  • Add New Booking — crm/booking_add.php (manual booking entry).

How booking confirmation works (live today)

  1. Open Quotations list.
  2. Click Book on a quotation.
  3. Fill Confirm Tour modal details.
  4. Save confirmation — quotation flagged tour_confirmed.
  5. Linked lead stage moves to Confirmed.
Instruction: Treat “Confirm Tour” on Quotations as the operational booking gate. Use Bookings menu for dedicated booking records/management when those screens are in use.

5 Customers

Sidebar: All Customers · Add New Customer

Purpose

  • Store confirmed / repeat guest profiles separately from active leads.
  • Keep contact history for future tours and remarketing.

How to use

  1. Open CRM → Customers → All Customers.
  2. Search existing customer by name/phone/email.
  3. Click Add New Customer to create a profile.
  4. Link future leads/quotations to known customers when repeating business.
Instruction: After a lead is Confirmed, maintain the guest as a Customer for long-term relationship management.

6 Suppliers

Page: crm/suppliers.php · Hotel / Flight / Ground / other vendor directory

Add Supplier→ Contacts + Services→ City / Places→ Use in Quotation / Mail

How to add a supplier

  1. Open CRM → Suppliers.
  2. Click Add Supplier.
  3. Enter supplier name, website, city/country.
  4. Add one or more contacts (name, email, mobile).
  5. Select Supplier Of services (hotel, flight, vehicle, etc.).
  6. Attach places/destinations they cover.
  7. Set Active and Save.

Features

  • List with filters by city / service type.
  • Edit / delete supplier.
  • Primary contact shown in list.
  • Used in quotation hotel/flight supplier pickers.
  • Used when sending supplier emails from quotation.
  • Supports legacy import of old suppliers.
Instruction: Keep emails accurate — supplier mail from quotations depends on these contacts.

7 Users

Page: crm/users.php · CRM staff accounts for assignment

How to manage users

  1. Open CRM → Users.
  2. Add user: username, password, full name, user type.
  3. Optional profile image upload.
  4. Edit / soft-delete users as needed.
  5. Active users appear in Lead Assign To list.

Why it matters

  • Controls who owns each lead.
  • Shows assignee avatar/initials on Leads table.
  • Supports team workload visibility.
Instruction: Create CRM users before assigning leads. Use clear usernames so the Leads “Assigned” column stays readable.

8 Reports

Sidebar: crm/reports.php · performance & pipeline analytics

What reports are for

  • Lead volume by stage / source / assignee.
  • Quotation conversion (Quoted → Confirmed).
  • Revenue / booking performance over date ranges.
  • Team productivity and lost-reason analysis.

How to use

  1. Open CRM → Reports.
  2. Select date range / financial year.
  3. Filter by user, destination, or stage if available.
  4. Export or share findings with management.
  5. Feed insights back into Masters pricing and lead sources.
Instruction: Review reports weekly. High “Lost” or stuck “Quoted” leads usually mean follow-up or pricing issues.

9 Settings

CRM → Settings · Email Configuration · Email Master · Import Legacy Data

Email Configuration

  1. Open Settings → Email Configuration (office_settings.php).
  2. Configure office/SMTP related options used for CRM mail.
  3. Save and test sending if available.

Email Master

  1. Open Settings → Email Master.
  2. Maintain sender identities (from name / from email).
  3. These populate quotation supplier mail “From” options.

Import Legacy Data

  1. Open Settings → Import Legacy Data.
  2. Run staged import: suppliers → customers/leads → quotations.
  3. Use Repair quotations if older JSON formats need fixing.
  4. Use Create leads from quotations if leads list is incomplete.
  5. Cleanup temporary staging tables when finished.

Settings checklist

  • SMTP / senders working before mailing quotes.
  • Legacy import only on staging/backup-aware runs.
  • After import, verify Leads + Quotation List + open one quote editor.
Instruction: Configure Settings first on a new deployment, then Masters, then start creating live leads/quotations.

∞ Full CRM lifecycle (put it together)

Login→ Settings + Masters + Users + Suppliers→ Create / Approve Lead→ Quotation Wizard 1–6→ Save + Send PDF/Mail→ Confirm Tour / Booking→ Customer record→ Reports & improve

Daily agent workflow

  1. Check Pending intake forms.
  2. Work New Lead queue — call, update notes, assign.
  3. Create / update quotations for active leads.
  4. Follow up Quoted leads; confirm wins.
  5. Mark lost deals; clean Trash periodically.

Manager workflow

  1. Maintain Masters quality (hotels, terms, sources).
  2. Review Suppliers & Users.
  3. Monitor Confirmed vs Lost in Reports.
  4. Audit Email Master senders.
  5. Approve process changes / legacy imports carefully.
